# Design System HRL

Este documento registra os tokens visuais oficiais do projeto.

## Cores

- `#d8a6a2`: rosa de destaque.
- `#5d6752`: verde institucional.
- `#f5f3ef`: fundo base e superfícies claras.
- `#402237`: cor principal de texto e contraste.

## Fontes

- `Poppins`: títulos, chamadas e elementos de destaque.
- `Rubik`: texto corrente, descrição e leitura longa.
- `Lumios Marker`: uso muito pontual, apenas como assinatura de marca.

## Regras de uso

- Não introduzir uma nova cor sem revisar o sistema de tokens.
- Não usar Lumios Marker em títulos longos ou blocos de leitura.
- Manter contraste alto entre texto e fundo.
- Reutilizar a mesma linguagem visual em todas as seções.
